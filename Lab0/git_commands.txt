git clone git-clone — клонирует репозиторий на компьютер
git status — показывает текущее состояние репозитория
git add — добавляет изменения файлов
git commit — создает коммит
git push — отправляет локальные комиты в репозиторий
git init — создает новый пустой локальный репозиторий в текущей папке
git pull — скачивает изменения из репозитория и объединяет их с текущей локальной веткой
git log — выводит историю коммитов с именами авторов, датами и хэшами
git branch — создает ветку
git checkout — переключается между разными ветками
